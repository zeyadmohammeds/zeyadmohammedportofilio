# Gym Website — Fitness Club Landing Page

![Gym Website Preview](https://i.ibb.co/fd0vLZSW/image.png)

A modern, responsive landing page concept for a fitness club, designed to present training programs, build trust with social proof, and make it easy for potential members to get in touch.

## Live Demo

**Production:** https://gym-phi-lake.vercel.app/

## Project Overview

This project explores how a gym can present its brand and services through a polished digital experience. It combines a clear landing-page structure with interactive elements and responsive layouts.

## Key Features

- Responsive layout for desktop, tablet, and mobile screens
- Hero and promotional sections for the fitness brand
- Training program and service sections
- Testimonials to highlight member feedback
- Before-and-after image comparison slider
- Smooth animations and interactive UI elements
- Contact form with a serverless API endpoint
- Deployment on Vercel
